
# unimog-preparator
Набор Python-скриптов для подготовки данных и визуализации результатов анализа геномных перестроек с использованием программы [UniMoG](https://github.com/UniMoG).
Проект автоматизирует преобразование списков ортологов в формат UniMoG, автоматически обнаруживает и корректирует инверсию порядка генов между сравниваемыми видами, а также строит графики синтении для визуальной оценки коллинеарности геномов.

### 1.Подготовка данных (`preparation_for_unimog.py`)
* Читает списки ортологичных генов двух видов (по одному ID на строку).
* Строит числовое сопоставление: парные ортологи получают одинаковый числовой ID.
* Извлекает реальный хромосомный порядок генов из FASTA-файлов протеомов.
* Автоматически определяет инверсию: если порядок генов второго вида зеркален, скрипт разворачивает список перед записью.
* Генерирует итоговый файл в формате UniMoG (`>SpeciesName`, маркер `|`).

### 2. Визуализация синтении (`plot_synteny.py`)
* Парсит выходной файл UniMoG и извлекает порядки генов.
* Строит диаграмму: позиция гена в геноме вида 1 vs позиция гомологичного гена в геноме вида 2.
* Рассчитывает и добавляет линию линейного тренда.
* Сохраняет график в высоком разрешении.
